# Salesforce Metadata

This folder is reserved for Salesforce metadata retrieved or created in the project org.

## Planned content
After implementation, this folder may contain Salesforce DX source-format metadata such as object definitions, fields, flows, layouts, permission sets, and other supported components.

## Current status
No Salesforce metadata is included in this starter pack. The documents in sibling folders are design artifacts, not deployable configuration.

Before adding metadata:
1. Confirm the target org and project setup.
2. Retrieve supported metadata using Salesforce CLI / Salesforce DX.
3. Review the diff and remove secrets or org-specific sensitive information.
4. Commit changes with a meaningful message.
5. Document dependencies and deployment/test steps.
