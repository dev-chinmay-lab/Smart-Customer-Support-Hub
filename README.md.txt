
# Smart Customer Support & Resolution Hub

## Project Overview
A Salesforce portfolio project designed to improve customer support
operations for a fictional e-commerce company, NovaCart.

## Business Problem
Manual case assignment, inconsistent prioritization, slow escalations,
and limited visibility into support performance can affect customer
experience and resolution efficiency.

## Project Objectives
- Organize customer cases and related records.
- Design a role-based Salesforce security model.
- Automate case classification and escalation using Flow.
- Plan intelligent routing using Omni-Channel.
- Support agents with Knowledge and Agentforce.
- Track service performance through reports and dashboards.

## Technology Stack
- Salesforce Platform
- Service Cloud
- Salesforce Flow
- Reports and Dashboards
- Agentforce (planned)
- Salesforce DX / Git (as implementation progresses)
